# learn-brain

Bộ não học lập trình thời AI của riêng tôi (repo private).

**Mục tiêu:** vibe code chuẩn dev: hiểu vì sao code chạy/không chạy, biết sai ở đâu, biết dự án đang ở giai đoạn nào và cần làm gì tiếp.

**Cách dùng:** mở phiên với AI nào cũng gõ: "Đọc AGENTS.md rồi bắt đầu phiên."

| File | Vai trò |
|---|---|
| AGENTS.md | Luật cho AI |
| SPEC.md | Brain vận hành thế nào |
| PROFILE.md | Mục tiêu và trình độ hiện tại |
| ROADMAP.md | Lộ trình, tiêu chí qua từng phase |
| MAP.md | Sơ đồ tiến độ |
| LOG.md | Nhật ký phiên và sổ lỗi |
| exercises/ | Bài tập theo phase |
| templates/ | Mẫu ghi chú |
